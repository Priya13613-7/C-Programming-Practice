# C Programming Practice

A collection of simple C programs created while learning programming fundamentals.

## Programs Included

1. Largest of Three - if conditions
2. Calculator Using Switch - switch-case and operators
3. Even or Odd - conditional statements
4. Prime Number - loops and conditions
5. Reverse Number - while loop and arithmetic
6. Palindrome Number - loops and number manipulation
7. Armstrong Number - loops and arithmetic
8. Student Names Array - arrays, strings and searching
9. Sum Using Function - functions
10. Star Pattern - nested loops

## Topics Practised

- Variables and data types
- Operators
- Conditional statements
- Switch-case
- For and while loops
- Arrays
- Strings
- Functions
- Basic problem solving

## How to Run

Compile a program with GCC:

```bash
gcc 01_largest_of_three.c -o largest
```

Then run it:

```bash
./largest
```
